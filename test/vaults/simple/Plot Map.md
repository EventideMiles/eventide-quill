# Plot Map

A working diagram of the test manuscript's plot threads. Linked from each chapter's `plotMap` frontmatter.

## Acts

1. **Arrival** — Elaine lands at Saltmere, is led to Magda Vos.
2. **Revelation** — Magda reveals the relic is a key; the order is awake.
3. **Departure** — Elaine rides north with the relic, toward a village with a red door.
